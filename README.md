# 🛡️ AI Travel Insurance & Compensation Assistant

An intelligent travel insurance and claim processing assistant that automates delay alerts, cancellation guidance, and lost baggage compensation claims using Python, Flask, and Generative AI.

---

## 🛠️ Tech Stack

* **Programming Language:** Python
* **Backend Framework:** Flask (REST API)
* **Generative AI:** Google Gemini API / LLMs
* **Tools & IDE:** VS Code, Git, GitHub

---

## ✨ Key Features

* **📦 Lost Baggage Claim Automation:** Guides users through claiming compensation for delayed or lost luggage.
* **✈️ Delay & Cancellation Support:** Automatically calculates compensation eligibility based on flight delay duration.
* **📜 Travel Insurance Guidance:** Provides clear, step-by-step guidance on travel insurance policies and coverage.
* **⚡ Instant Query Resolution:** Instant AI assistance for urgent travel disruptions.
